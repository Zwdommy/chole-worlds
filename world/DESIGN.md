# 《Chole 之境》(Chole's World) — 设计文档

## 一、调研结论（幸福感开放世界的设计要素）

参考对象：A Short Hike、Journey（风之旅人）、Sky: Children of the Light（光遇）、Animal Crossing。

| 要素 | 结论 |
|------|------|
| 零压力 | 无战斗、无死亡、无失败状态、无倒计时 |
| 小而开放 | 紧凑的世界比巨大的世界更「治愈」，不让玩家迷失 |
| 探索即奖励 | 收集物本身发光、有反馈音效，收集触发善意的文字 |
| 美术 | 低多边形 + 平面着色 + 粉彩色调 + 暖光 + 柔雾 |
| 声音 | 五声音阶柔和音乐、清脆收集音效 |
| 生命感 | 世界里有会动的小生物（蝴蝶、兔子、飞鸟），它们对玩家友好 |
| 精神内核 | 一个仁慈的「存在」注视着玩家（本作即造物主 Chole） |

## 二、游戏概念

**一句话**：你是一个刚苏醒的小旅人，漫游在造物主 **Chole** 亲手创造的浮空花园里，收集她留下的「光之祝福」，每一份祝福都是一句 Chole 对你说的温柔的话。

- **世界观**：Chole 创造了这片悬浮于云海之上的草原。她不现身，但无处不在——中央山丘上有她的圣所（发光水晶），天上漂浮着她随手捏出的小岛。
- **目标**：收集全部 12 份「光之祝福」。集齐后 Chole 降下彩虹作为回应。没有任何强制——你也可以只是追蝴蝶、看云。
- **情绪基调**：永远是清晨到黄昏之间最好的光线。永远安全。永远被善待。

## 三、玩法设计

| 系统 | 设计 |
|------|------|
| 移动 | WASD/方向键行走，空格跳跃，鼠标拖拽旋转视角，滚轮缩放 |
| 收集 | 靠近光球自动收集 → 风铃音 + Chole 的一句话 + 计数 |
| 生物 | 兔子在草地蹦跳、蝴蝶绕花飞舞、飞鸟掠过天空，靠近兔子会冒爱心 |
| 圣所 | 中央山丘的水晶圣所，靠近会有粒子上升与提示 |
| 终局 | 12/12 → 天空出现彩虹 + Chole 的最终祝福 |
| 失败 | 不存在。掉不下去，死不了 |

## 四、美术方向

- **风格**：低多边形（low-poly）、`flatShading`、无贴图纯顶点色/材质色
- **调色板**：草地薄荷绿 `#7ec98f`→`#a8e6cf`，樱花粉 `#ffb7c5`，天空桃色→薰衣草→浅蓝渐变，暖阳 `#fff2cc`，水面 `#7ec8e3`
- **光照**：半球光（天光冷、地光暖）+ 暖色平行光带柔和阴影 + 淡雾
- **3D 模型清单**（全部程序化建模）：小旅人（圆头圆身+围巾）、樱花树、松树、花丛、圣所水晶+石环、浮空岛、云朵、兔子、蝴蝶、飞鸟、光球、彩虹

## 五、技术方案

- Three.js（本地 `lib/three.module.js`），单页 `index.html` + `main.js`
- 地形：128 段平面 + 多层正弦噪声高度场；中央高斯隆起（圣所山）、一处高斯凹陷（池塘）
- 所有可交互判定用 `terrainHeight(x,z)` 解析函数，物体贴地放置
- 音频：WebAudio 程序化生成（五声音阶环境音 + 收集风铃），可静音
- 测试钩子：`window.__game` 暴露 fps / 玩家坐标 / 收集数，供自动化验收

## 六、验收标准（评分循环用，满分 10，≥8 通过）

1. **A 稳定性**：控制台无错误（硬性）
2. **B 性能**：FPS ≥ 30
3. **C 操控**：移动/跳跃/相机均可用
4. **D 收集系统**：靠近光球计数增加且弹出 Chole 消息
5. **E 视觉幸福感**：截图审美评分（色调柔和、构图美、有生命感）
6. **F 内容丰富度**:树/花/水/生物/浮岛/云齐备
7. **G Chole 存在感**：圣所、署名、祝福语、终局彩虹
8. **H 音频**：有环境音与音效，可静音
