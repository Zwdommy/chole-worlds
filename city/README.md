# 《Chole 之城》— 造物主 Chole 的城市（时间与主线版）

Chole 在云海之上造了一座糖果色小城。这一版，小城拥有了**完整的一天**和**一条八章的幸福主线**：
从黎明落在云上开始，问好、送信、摸狗、点灯、看天灯节，到星夜集齐十二道光，等来彩虹的黎明。

**设计文档：[TIMELINE.md](TIMELINE.md)**（幸福感拆解 / 全天时刻表 / 章节流程图 / 幸福度经济 / 验收标准）

## 运行

```bash
cd chole-city
python3 -m http.server 8935
# 浏览器打开 http://localhost:8935
```

（Three.js 与全部模型均已本地化，无需联网。）

## 一天的时间线（一个游戏日 ≈ 8 分钟）

黎明 🌅 → 清晨 🌤️ → 正午 ☀️ → 午后 🌞 → 黄昏 🌆 → 夜晚 🌙 → 星夜 ✨ → 新的黎明

- 11 个光照关键帧插值驱动：天空三层渐变、雾色、太阳/月亮方位与颜色、星空、灯光
- 章节会温柔地"快进"时间到对应时段（40×，天空可见地流动）
- 路灯/门前灯笼/彩灯串/车头灯随黄昏渐次点亮；深夜居民回家、鸽子归巢、萤火虫醒来
- 星夜限定：流星（40-70 秒一颗）；钟楼表针与世界时间同步

## 八章主线（一切目的：让玩家感到幸福）

| 章节 | 时段 | 玩法 | 情感目标 |
|------|------|------|----------|
| 序章·落在云上的羽毛 | 黎明 | 前往喷泉广场 | 被迎接 |
| 一·五声早安 | 清晨 | 向 5 位居民问好 | 联结 |
| 二·阳光邮差 | 正午 | 送 3 封发光的信 | 被需要 |
| 三·毛茸茸的时光 | 午后 | 摸柴犬 ×3 | 允许浪费时光 |
| 四·点灯人 | 黄昏 | 亲手点亮 7 盏路灯 | 身份翻转：照顾者 |
| 五·天灯节 | 夜 | 广场观看 30 盏天灯升空+烟花 | 被集体回馈 |
| 六·十二道光 | 星夜 | 集齐 12 个光之祝福 | 亲密的回顾 |
| 终章·彩虹的方向 | 不快进 | 等夜色变薄，登樱花公园 | 等待后的圆满 |

## 幸福度（0-100）

问候 / 送信 / 摸狗 / 点灯 / 收集 / 小憩都会累积。数值必须长出形状：

- **25**：天上多 3 只飞鸟 ｜ **50**：广场绽放花环 + 走过的路开花 ｜ **75**：夜光更柔（Bloom 增强）+ 萤火虫更亮 ｜ **100**：钟楼光柱增辉 + 大烟花

## 其他沉浸细节

- 萤火虫会亲近玩家（绕着你转，不逃开）；长椅小憩有专属台词与和弦
- 音景随时间流转：清晨鸟鸣、夜晚蟋蟀与低八度旋律、钟楼报时
- Bloom 后处理（桌面端），夜晚灯光真正发光；手机端自动降级不降爱
- 手机虚拟摇杆 + 触屏视角完整支持

## 技术

- 关键帧昼夜系统（颜色/强度/仰角插值，回绕安全）；快进到站判定按实际步长（后台节流也不会过站）
- 数据驱动任务引擎：7 种目标类型（visit/greet/deliver/lamps/pet/watch/collect），模拟时间驱动章节切换
- `window.__game` 验收钩子 + `step(n, dt)` 确定性步进（完整剧情线可自动化仿真）
- 实测：~450 draw calls，桌面 100+ FPS（含 Bloom），零控制台错误跑完全部八章
