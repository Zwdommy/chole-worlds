# 《Chole 之城》(Chole's City) — 设计文档

草原版《Chole 之境》的姊妹作：同一个造物主 Chole，这次她造了一座**云上的糖果色小城**。

## 调研参考

- **Townscaper**：粉彩房子 + 水面 = 「幸福城市」美学的标杆
- **动物森友会**：小尺度城镇、友好居民、无压力节奏
- **Sky光遇 / 天空之城**：悬浮于云海的城市带来「被托住的安全感」
- 城市要「活」：会动的小车、散步的行人、广场鸽、热气球、亮着的窗灯

## 世界概念

Chole 把一座小城放在云海之上。钟楼是她的灯塔——整座城的时间以你的脚步为准。
街灯永远提前为你点亮，车永远会让你先走，长椅永远有你的位置。

## 城市布局

- 十字路网：道路中心线在 x/z = ±28、±72，城半径约 110，之外坠入云海
- **中央广场**（±24）：Chole 钟楼（水晶信标 + 光柱）、喷泉、花坛、长椅、路灯环
- **8 个街块**：糖果色小楼（1–3 层，暖黄窗灯、金字塔屋顶、烟囱）
- **公园街块**（东北角）：樱花、松树、花海、小池塘
- 城外一圈防风林 + 天上热气球 + 云海

## 活物 & 交互

| 对象 | 行为 |
|------|------|
| 小车 ×8 | 沿街区环线行驶，玩家靠近会礼貌停下 |
| 居民 ×8 | 沿人行道散步，靠近冒爱心 |
| 广场鸽 ×5 | 在广场蹦跳啄食 |
| 热气球 ×4 | 高空缓慢漂移 |
| 钟楼 | 表针随世界时间转动；靠近触发 Chole 问候 |
| 光之祝福 ×12 | 散布全城，收集触发 Chole 的城市情话；集齐降彩虹 |

## 美术

- 墙面：`#ffd6e0 #ffe8cc #d9f2e6 #cce7ff #f3e6ff #fff3b0`；屋顶：珊瑚/砖红/雾蓝/豆绿
- 道路暖灰、广场奶油色石板、窗灯 `#ffd88a` 自发光
- 天空/云海/暖阳沿用草原版（桃色→薰衣草→浅蓝）

## 技术

- 与草原版同栈：Three.js 本地化、程序化建模、WebAudio 程序化音频
- 建筑/喷泉/钟楼有圆形碰撞体（push-out），车辆有让行 AI
- `window.__game` 验收钩子（含障碍物距离、车辆/居民坐标）

## 验收标准（同草原版 8 项，新增 2 项）

1. A 无控制台错误（硬性） 2. B FPS≥30 3. C 操控 4. D 收集系统
5. E 视觉幸福感 6. F 内容丰富度 7. G Chole 存在感 8. H 音频
9. **I 碰撞**：玩家不能穿墙进建筑 10. **J 城市生命感**：车会让行、居民冒爱心
