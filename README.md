# Chole 的世界 🌸🏙️

造物主 **Chole** 创造的两个特别幸福、特别美好的开放世界，用 Three.js 制作，支持电脑与手机浏览器。

**▶ 在线游玩：https://zwdommy.github.io/chole-worlds/**

| 世界 | 简介 |
|------|------|
| [🌸 Chole 之境](https://zwdommy.github.io/chole-worlds/world/) | 云海上的樱花草原：收集 12 份光之祝福、和兔子做朋友、圣所与彩虹 |
| [🏙️ Chole 之城](https://zwdommy.github.io/chole-worlds/city/) | 糖果色云上小城：让行的小车、跟随的柴犬、钟楼与热气球 |

## 操作

- **电脑**：WASD/方向键移动 · 空格跳跃 · 鼠标拖拽转视角 · 滚轮缩放
- **手机**：左侧虚拟摇杆移动 · 右侧滑动转视角 · ⬆ 按钮跳跃
